# UI v1.1.1

共有されたデザイン見本に合わせた、表示層のみの改修です。

- 青のグラデーションヘッダー、白いカード、円形手順番号。
- 右上に最新の支給バナー、左下に支給されたノートPC猫。
- 別途指定されたみかん帽子の猫を32px透過PNGファビコンに設定。
- 形式選択チップ、詳しさ、折りたたみ詳細設定、選択件数付きZIPボタン。
- 長文プレビューと結果一覧、狭い画面の1列表示。

`js/app.js`、`js/content-engine.js`、`js/exporters.js` とすべてのデータ定義は変更しません。元画像はWeb表示用に縮小・WebP圧縮しています。faviconは新たに指定された画像の周囲の余白を除き、アスペクト比を保って32pxへ収めています。生成文書の中には猫を入れません。

ブラウザ回帰テストは既存の全文保持・4形式・ZIPの検証を維持し、折りたたみ設定を開く操作のみ追加。`tests/ui.test.mjs` は画像のSHA-256、ファビコン設定、フィルタ、選択状態、詳細設定、プレビュー、7画面幅を検証します。
