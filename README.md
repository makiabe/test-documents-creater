# DOCUMENTS CREATOR v1.2.0

https://makiabe.github.io/test-documents-creater/

## 更新点

16業種、33職種、231利用シーン、12文書種類。従来の7業種・8職種・24シーン・6種類から拡充しました。

追加業種は商社・卸売、建設・設備、不動産、宿泊・観光、飲食、医療・福祉の事務、金融・保険の事務、広告・制作、コンサルティングです。既存業種も2職種ずつ収録しています。追加文書は会議議事録、業務改善提案書、業務要件定義書、受入テスト仕様書、不具合・トラブル報告書、業務引継書です。IT・情報サービスには、基幹業務システム刷新を題材にしたITプロジェクトマネージャーの架空ケースを追加し、WBS、課題・リスク、変更要求、外部連携、テスト、移行、リリース、運用・障害対応を含むプロジェクト引継ぎ資料を生成できます。

職務経歴書は専用ジェネレーターに変更。基本情報、要約、学歴、勤務先、所属・役職の推移、期間別経歴、2つのプロジェクト（標準は1つ）、資格、スキル、自己PRを含みます。WordとPDFとHTMLプレビューは表組み、ExcelとPowerPointには表の内容と本文を欠落なく収録します。商社・卸売の「DX推進・業務改革」は、提供された参考例を基に2000年入社から現在までの5部署の経歴を持ちます。ほかの職種は各業務の手順・課題・事例から職種別の経歴を作成します。

氏名、生年月日、学歴、勤務先、資格取得、成果の数値はテスト専用の架空情報です。実在の人の履歴を加工したものではありません。住所、電話、メール、秘密情報は生成しません。資格や業務制度の公的な説明資料ではなく、医療判断や金融商品の判断を行うデータでもありません。

日付基準は再現性のため2026-09-27で固定し、年齢は生年月日から計算。所属期間は連続、年間削減時間は処理時間差×月間件数×12÷60で算出します。RAG評価の期待回答は同じ生成済みの事実に基づき、評価フォルダは検索対象から分離します。各文書は独立ケースで、50件すべてがゼロから執筆した異なる原稿ではありません。

ヘッダーはPCで高さ124pxから170px、上余白8pxから28pxへ調整。カードの横幅、ロゴ、猫の素材、ファビコンは維持しています。

## データの追加

通常の追加は `data/industries/<業種>.json` の `profiles` と `data/manifest.json` を編集します。`career` に学部、事業内容、資格、研究テーマを指定できます。文書の種類は `data/templates/longform.json` に追加し、職種の `scenes[].templates` に登録します。職務経歴書だけは `renderer: "resume"` を指定する専用構成です。

`scripts/business-seeds.mjs` と `scripts/build-business-data.mjs` は本版の初期投入用です。後からJSONを手で編集した場合は再実行で上書きしないよう注意してください。`scripts/apply-v1.2.mjs` は旧版からの一回限りの移行用で、通常のデータ追加には不要です。


## 検証

`npm test`、`npm run test:resume`、`npm run test:browser`、`npm run test:resume-browser` を実行します。ブラウザ検証にはChromiumとpdftotextを使用します。
