# Test Documents Creator

GitHub Pages上で動作する、テスト用の架空業務ドキュメント生成アプリです。

## v1.0
- 業種 → 職種 → 業務・利用シーンで絞り込み
- 作成可能な文書と含有項目を表示
- XLSX / DOCX / PPTX / PDF を複数選択
- 10 / 30 / 50件生成
- HTMLプレビュー、個別保存、複数選択ZIP保存
- サーバー送信なし。ブラウザ内で生成
- アプリ・データ定義はUTF-8
- 実在人物・企業・製品を使わないテストデータ設計

## データ追加
`data/catalog.json` に業種、職種、シーン、ドキュメント定義を追加します。UIロジックを変更せず拡張できます。

> TEST DATA ONLY — 生成物はテスト用途の架空データです。
